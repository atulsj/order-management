# Backend file reference

This reference explains where to make a change. Empty `__init__.py` files mark Python packages; model and payment integration package initializers additionally export public names.

## Build and runtime files

| File | Responsibility |
|---|---|
| `backend/pyproject.toml` | Python 3.12 runtime/dev dependencies and Ruff, Pyright, pytest, coverage configuration |
| `backend/uv.lock` | Exact reproducible dependency resolution; generated by `uv` |
| `backend/requirements.txt` | Exported compatibility view; `pyproject.toml`/`uv.lock` remain authoritative |
| `backend/Dockerfile` | Non-root, multi-stage backend image with locked production dependencies |
| `backend/.dockerignore` | Excludes secrets, caches, tests, and local environments from image context |
| `backend/.env.example` | Native-development setting names and safe local examples |
| `backend/compose.yaml` | Complete local backend topology and health dependencies |
| `backend/alembic.ini` | Alembic paths, fallback URL, and migration logging |
| `keycloak/oms-realm.json` | Local learning realm, SPA client, audience mapper, roles, and demo users |
| `scripts/postgres/init-test-db.sql` | Creates the isolated integration-test database only when PostgreSQL initializes a fresh Compose volume; it does not create OMS tables |
| `observability/prometheus/prometheus.yml` | Scrapes API metrics in local Compose |
| `observability/grafana/provisioning/datasources/prometheus.yaml` | Provisions local Prometheus datasource |

## Application entry and API composition

| File | Responsibility |
|---|---|
| `app/main.py` | FastAPI factory, lifespan, middleware, versioned router, health/readiness, metrics, telemetry |
| `app/seed.py` | Idempotently seeds learning warehouses, products, inventory, and receipt movements |
| `app/api/v1/router.py` | Aggregates all version-one resource routers under `/api/v1` |
| `app/api/__init__.py`, `app/api/v1/__init__.py` | Package boundaries |

## Core infrastructure

| File | Responsibility |
|---|---|
| `app/core/config.py` | Typed environment settings and validation; cached settings accessor |
| `app/core/auth.py` | Bearer parsing, JWKS lookup, JWT claim validation, `Principal`, role dependencies |
| `app/core/errors.py` | RFC 7807-style problem responses and validation/HTTP exception handlers |
| `app/core/logging.py` | JSON or development structlog configuration |
| `app/core/middleware.py` | Request IDs, duration/security headers, body limit, Redis-backed mutation limits |
| `app/core/telemetry.py` | Sentry, OTLP tracer provider, FastAPI/SQLAlchemy/HTTPX instrumentation |

## Database

| File | Responsibility |
|---|---|
| `app/database/base.py` | SQLAlchemy declarative base |
| `app/database/connection.py` | Engine/pool configuration, slow-query timing, session factory/dependency |

The request dependency closes every session. Services explicitly commit or roll back their transaction.

## Persistence models

| File | Tables and purpose |
|---|---|
| `app/models/product.py` | `products`: commercial product/SKU/price/active state |
| `app/models/warehouse.py` | `warehouses`: allocation priority and active state |
| `app/models/inventory.py` | `inventory`: per-warehouse on-hand and reserved quantities |
| `app/models/stock_movement.py` | `stock_movements`: append-only physical stock ledger |
| `app/models/customer.py` | `customers`, `customer_addresses`: Keycloak subject mapping and saved addresses |
| `app/models/order.py` | `orders`: owner, state, currency, total, timestamps, relationships |
| `app/models/order_item.py` | `order_items`: product, quantity, purchase-time price |
| `app/models/order_event.py` | `order_addresses`, `order_events`: checkout snapshot and audit timeline |
| `app/models/allocation.py` | `inventory_allocations`: exact reservation per item/inventory |
| `app/models/payment.py` | `payments`: attempts, two keys, provider state, review/retry/deadline metadata |
| `app/models/refund.py` | `refunds`: paid cancellation/refund state |
| `app/models/shipment.py` | `shipments`, `shipment_items`: warehouse fulfillment and allocation consumption |
| `app/models/integration_event.py` | `outbox_events`, `webhook_inbox`, `simulator_transactions` |
| `app/models/enums.py` | Named domain status enums used as a vocabulary |
| `app/models/__init__.py` | Imports all models so SQLAlchemy metadata/relationship resolution sees every table |

## API schemas

| File | Contracts |
|---|---|
| `app/schemas/product.py` | Product create/update/detail and paginated catalog with aggregate availability |
| `app/schemas/warehouse.py` | Warehouse create/update/detail |
| `app/schemas/inventory.py` | Inventory create/receive/adjust/detail and movement response |
| `app/schemas/customer.py` | Saved address and customer profile |
| `app/schemas/order.py` | Checkout items/address, allocations, events, detail, list |
| `app/schemas/payment.py` | Payment create/detail/list, client config, refund detail |
| `app/schemas/shipment.py` | Shipment create/update/items/detail |

Pydantic schemas are the public boundary. Do not return provider SDK objects or expose provider keys/review details accidentally.

## HTTP routers

| File | Endpoints and authorization |
|---|---|
| `app/routers/product.py` | Public catalog read; admin mutations |
| `app/routers/warehouse.py` | Operator read; admin create/update |
| `app/routers/inventory.py` | Public specific availability where exposed; operator lists/receipts; admin adjustments |
| `app/routers/customer.py` | Authenticated profile/address ownership |
| `app/routers/order.py` | Customer checkout/list/detail/cancel; operator/admin broader scope |
| `app/routers/payment.py` | Provider client config, create/list/reconcile, unauthenticated signed Stripe webhook |
| `app/routers/shipment.py` | Operator/admin shipment creation, ship, delivery |

Routers should remain thin. Transaction logic belongs in services.

## Where to add a feature

- New HTTP field: schema, service, model/migration if persisted, router, tests, docs.
- New state transition: service plus event/outbox, race/failure tests, state diagram update.
- New provider: implement `PaymentProvider`, factory selection/configuration, contract tests.
- New background workflow: persist durable schedule/intent first, add idempotent task and queue route, runbook/metrics.
- New model: import in `models/__init__.py`, create migration, update fixture cleanup order.
